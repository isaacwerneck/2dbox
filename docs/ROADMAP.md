# 2DBox Roadmap

## 1. Milestone Plan

### Milestone 0: Foundations (2 weeks)
- Finalize requirements and architecture baseline.
- Prepare UX flows and wireframes for core MVP loops.
- Define engineering standards and branching strategy.

Deliverables:
- Approved requirements docs.
- UI flow map.
- Technical implementation backlog.

### Milestone 1: Core Platform (3 weeks)
- Auth, profiles, and friendship model.
- Notification foundation.
- Initial moderation report pipeline.

Deliverables:
- End-to-end auth and friendship flows.
- Basic admin moderation queue.

### Milestone 2: House Experience (4 weeks)
- House rendering and tile placement engine.
- Furniture placement persistence.
- Visit flow with guestbook and reactions.

Deliverables:
- Fully functional user house loop.

### Milestone 3: Park Realtime (4 weeks)
- Presence sync and movement.
- Park chat and avatar interactions.
- Instance cap and sharding baseline.

Deliverables:
- Shared park with stable 20-30 user instance target.

### Milestone 4: Stabilization and Beta Prep (3 weeks)
- Performance tuning.
- Safety and moderation hardening.
- QA, bug fixing, and operational readiness.

Deliverables:
- Closed beta candidate build.

## 2. Post-MVP Sequence
### Phase A
- Cosmetic shop and starter economy.
- Discovery improvements.

### Phase B
- Seasonal content and progression badges.
- Expanded social events in park.

### Phase C
- Groups/neighborhood concepts.
- Advanced creator and customization systems.

## 3. Risk Register (Top)
- Realtime desync under network variance.
- Moderation throughput during sudden growth.
- Art production speed vs feature release cadence.

## 4. Risk Mitigation Themes
- Build observability for movement and chat events early.
- Keep closed beta cohort controlled before expansion.
- Ship with constrained furniture catalog and scale gradually.

## 5. Definition of Beta Readiness
- All MVP scope items are feature-complete.
- No unresolved critical incidents in core loops.
- Monitoring, moderation, and incident runbooks active.
- Core KPI instrumentation validated.
